# 🐊 CrocodileBot

**CrocodileBot** — Telegram-бот для игры в «Крокодила» в групповых чатах.

Бот загадывает слова, которые один из игроков должен объяснить остальным без использования самого слова. Остальные участники пытаются угадать загаданное.

## Возможности

- Выбор сложности слова: лёгкая, средняя и сложная.
- Выбор категорий слов.
- Автоматическая генерация случайного слова.
- Просмотр загаданного слова только для игрока, который будет его показывать.
- Проверка ответов участников.
- Хранение игровых сессий в SQLite.
- Возможность добавлять собственные слова через JSON.

## Технологии

- **Python 3**
- **aiogram 3** — работа с Telegram Bot API.
- **SQLite** — хранение игровых данных.
- **JSON** — хранение базы слов.

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/mazyadev/CrocodileBot.git
cd CrocodileBot
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация на Linux:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

Для работы бота необходимо создать Telegram-бота через [@BotFather](https://t.me/BotFather) и получить токен.

Перед запуском установите переменную окружения `BOT_TOKEN`.

Linux:

```bash
export BOT_TOKEN="YOUR_BOT_TOKEN"
```

Windows PowerShell:

```powershell
$env:BOT_TOKEN="YOUR_BOT_TOKEN"
```

## Запуск

```bash
python bot.py
```

После запуска бот будет ожидать сообщения и команды в Telegram.

## Команды

| Команда | Описание |
|---|---|
| `/start` | Запуск бота |
| `/newgame` | Создание новой игры |
| `/word <слово>` | Отправка предполагаемого ответа |

## Добавление слов

Слова хранятся в файле `words.json`.

Каждое слово содержит три параметра:

```json
{
    "word": "Попугай",
    "category_id": 1,
    "difficulty": "easy"
}
```

Доступные уровни сложности:

- `easy` — лёгкий;
- `medium` — средний;
- `hard` — сложный.

## База данных

Проект использует SQLite для хранения игровых сессий и слов.

Файл базы данных создаётся локально и не хранится в репозитории. Исходные слова находятся в `words.json`.
